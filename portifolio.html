Tailwind-Data(Dashboard)

I built a responsive dashboard using React.js with Tailwind CSS for styling. It includes login and registration forms, and once logged in, users access a structured dashboard with multiple child sections. The backend is powered by Node.js, Express.js, and MongoDB.
